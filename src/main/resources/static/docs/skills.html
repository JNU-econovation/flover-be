기술 스택

plover-be 프로젝트에서 사용하는 기술 스택 및 주의사항

Core

Java 21 Spring Boot 4.0.5 Spring Data JPA Spring Web MVC Bean Validation MySQL PostgreSQL Driver Lombok Gradle (Groovy DSL) AWS SDK v2 Caffeine SpringDoc OpenAPI
  • org.springframework.boot:spring-boot-starter-validation — Request DTO 검증, 파일 업로드 파라미터 검증
  • io.jsonwebtoken:jjwt-api:0.12.6 — JWT 생성·검증
  • com.github.ben-manes.caffeine:caffeine — Route Engine 성공 응답 JVM 인메모리 캐시
  • software.amazon.awssdk:s3 — S3 파일 저장, Presigned URL 발급
  • org.springdoc:springdoc-openapi-starter-webmvc-ui:2.8.6 — Swagger UI / OpenAPI 문서
  • runtimeOnly com.mysql:mysql-connector-j — 메인 MySQL 연결
  • runtimeOnly org.postgresql:postgresql — AI 원천 제보 선택 저장소 연결

테스트

JUnit 5 AssertJ Mockito Spring Boot Test

부하 테스트

k6
  • k6/scenarios/smoke-test.js — 핵심 API 정상 동작 확인
  • k6/scenarios/load-test.js — 일반 부하 상황의 응답 시간과 실패율 측정
  • k6/scenarios/stress-test.js — VU를 단계적으로 올려 병목 지점 확인
  • k6/scenarios/ai-analysis-smoke-test.js — AI 이미지 분석 API 별도 smoke 테스트

주의 사항

  • javax 패키지 대신 jakarta 패키지를 사용한다.
  • @Autowired 필드 주입을 사용하지 않는다. 생성자 주입만 사용한다. (Lombok @RequiredArgsConstructor 활용)
  • 프로젝트에 없는 외부 라이브러리(QueryDSL, MapStruct, Security 등)는 임의로 추가하지 않는다.
